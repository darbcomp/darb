# Darb E-commerce

Custom MERN e-commerce website for Darb Perfumes.

## Stack

- React + Vite
- Tailwind CSS
- Node.js + Express
- MongoDB + Mongoose
- Cloudinary
- Vercel
- Render

## Brand Direction

Darb is a perfume brand built around the idea of a path, memory, and emotional scent journey.

Main colors:
- Dark Green: #0F3D2E
- Beige: #E7DCC9
- Soft Gold: #C8A97E
- Black: #1C1C1C
